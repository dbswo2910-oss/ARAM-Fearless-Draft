# NOIR 개발 기록

## 기술 스택 (확정)

| 영역 | 선택 | 이유 |
|---|---|---|
| 웹 | Next.js 15 (App Router) + React 19 + TypeScript | 하나의 프로세스로 UI + API, 스트리밍 응답 지원 |
| DB | SQLite (better-sqlite3, WAL) | 설치 불필요한 단일 파일, 1인 사용에 충분, 백업이 파일 복사 |
| LLM | Ollama (`/api/chat` 스트리밍) | Windows 네이티브, CUDA 자동, 모델 교체 쉬움, `keep_alive` 로 VRAM 제어 |
| 인증 | 자체 구현 (scrypt + DB 세션) | 외부 계정 불필요, 단일 사용자 |
| 스타일 | 직접 작성한 CSS (외부 UI 키트·폰트 CDN 없음) | 오프라인 동작, 독립 디자인 |
| 이미지(예정) | ComfyUI API (SDXL 계열) | 로컬, 12GB 에서 SDXL 동작 |
| 음성(예정) | 로컬 한국어 TTS 엔진 (후보 비교 후 결정) | |
| 원격(예정) | Tailscale Serve (tailnet 내부 HTTPS) | 공개 인터넷 노출 없음 |

### 12GB VRAM 설계 원칙
- 기본값: 12~14B Q4 모델 + `num_ctx` 8192 + `num_predict` 700 → 약 9~11GB.
- 대화당 동시 생성 1개로 제한.
- `keep_alive` 기본 15분, 설정에서 "VRAM 비우기"(`keep_alive:0`) 제공 → 이미지 생성 단계에서 LLM 을 내린 뒤 ComfyUI 를 실행하는 순서 전환에 사용할 예정.

### 미완료 / 검증 대기
- **사용자 PC 에서 미검증**: 이 개발 환경은 Linux 클라우드 컨테이너이며 GPU·Ollama 가 없고 ollama.com 접근이 차단되어 있습니다. 실제 모델 대신 동일 프로토콜의 가짜 Ollama 로 검증했습니다. 실제 한국어 응답 품질·속도·VRAM 사용량은 PC 에서 확인이 필요합니다.
- `scripts/windows/diagnose.ps1`, `start.bat` 은 PowerShell/Windows 가 없어 실행 검증하지 못했습니다.
- 개발지시서 `NOIR_Chat_Claude_Code_개발지시서_20261117.md` 를 작업 폴더에서 찾지 못해, 사용자 메시지의 요구사항을 기준으로 진행했습니다. 파일을 받으면 차이를 반영합니다.
- 장기 기억(요약)은 DB 컬럼(`summary`, `summary_upto`)과 프롬프트 자리만 준비됨.

### 오류와 수정
1. 동시 요청이 409 로 거부돼도 사용자 메시지가 먼저 저장되던 문제 → 생성 잠금 확인을 저장 전에 수행.
2. 짧은 비밀번호가 400 이 아닌 500 반환 → `HttpError` 로 변경.
3. 서버 컴포넌트에서 클라이언트 모듈 함수(`avatarUrl`) 호출로 홈 500 → 공용 모듈로 이동.
4. **미들웨어 리다이렉트가 `localhost` 로 바뀌는 문제** (휴대폰/Tailscale 접속 시 로그인 불가로 이어질 버그) → 페이지 리다이렉트를 서버 컴포넌트(상대 경로)로 옮기고 각 페이지에서 세션 검증. 테스트 추가.
5. PowerShell 예약 변수 `$args` 를 매개변수명으로 쓴 실수 → `$argList`.

# v0.15.100 · RANDOM CANDIDATE PREVIEW LOCK

- 랜덤게임 픽창에서 TOP5/남은 챔피언 추천을 클릭했을 때 오른쪽 `조합 DNA`와 하단 빠른 판단이 잠깐 바뀐 뒤 TOP1 기준으로 되돌아가던 오류를 수정했습니다.
- 원인은 기존 Random Practice의 MutationObserver 자동 refresh가 수동 후보 미리보기 직후 기본 TOP1 DNA/빠른 판단을 다시 렌더링하던 상태 우선순위 충돌이었습니다.
- 수동으로 선택한 추천 후보가 TOP5에 남아 있는 동안에는 자동 refresh가 해당 후보를 우선 상태로 유지합니다.
- 오른쪽 DNA 5개 지표, 부족 역할, AD/AP, 선택 후보, 점수, 추천 방향이 같은 선택 후보를 계속 가리키도록 통일했습니다.
- 입력/추천 결과가 바뀌어 선택한 후보가 실제 TOP5에서 사라지면 선택 잠금을 해제하고 정상적으로 현재 TOP1 기준으로 복귀합니다.
- 선택 배지와 클래스는 상태가 실제로 바뀔 때만 갱신하여 불필요한 MutationObserver 재호출을 줄였습니다.
- 새 타이머/MutationObserver는 추가하지 않았습니다.
- 추천 순위, 챔피언 점수, 조합 산식은 변경하지 않았습니다.

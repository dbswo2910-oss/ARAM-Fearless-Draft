목표
- v0.15.51 실제 Windows 미리보기 캡처에서 확인된 중복/노이즈만 제거.
- 레이아웃 대공사는 종료하고, 살아있는 동안 1~2초 안에 읽히는 HUD를 사실상 고정.

변경
1. 상단 코치 버전 표기를 v0.15.52와 동기화.
2. LIVE 보조문구 정리
   - `행동 한 줄만 표시` 숨김
   - `이번 판 상황 보정` / 기본트리 일치 보조문구 숨김
3. 최고 위협 점수 표현 정리
   - `물리 · 84점` 같은 원점수 대신 `물리 · 위험 높음`처럼 해석된 표현 사용
   - 점수는 tooltip/상세 분석에서 확인 가능
4. 사망 화면 중복 제거
   - `사망 분석 · 부활 23초` -> `사망 분석`
   - 큰 부활 카운트다운은 그대로 유지
   - `부활까지 · 지금은 구매/분석 확인 시간` 제거
5. 인게임 중 전역 Source footer 숨김
   - 픽/데이터 화면에서는 기존처럼 유지

안전성
- 추천/위협/아이템/조합 점수 계산식 변경 없음.
- v0.15.50 코치 + v0.15.51 시각 우선순위 레이어 위의 UI 전용 미세정리.

ARAM Fearless Draft v0.15.50
Random In-game Coach HUD + Preview · Phase 1

목표
- 인게임에서 1~2초 안에 읽고 바로 행동할 수 있는 정보만 전면에 남김.
- 살아있을 때 / 사망 중 / 부활 직전의 정보 우선순위를 자동으로 다르게 보여줌.
- 실제 게임에 들어가지 않아도 프로그램 안에서 동일 UI를 미리 볼 수 있게 함.

변경
1. 기존 인게임 5탭(라이브 요약/아이템/위협 분석/한타 가이드/파워·타이밍)을 기본 화면에서 숨기고, 3탭으로 단순화.
   - LIVE
   - 빌드
   - 상세
2. AUTO 상태 전환
   - 생존: LIVE
   - 사망(부활 8초 이상): 빌드/분석
   - 부활 7초 이하: LIVE 부활 준비
   - 사용자가 AUTO OFF로 고정 가능
3. LIVE 화면 핵심 5요소
   - NOW CALL
   - 최고 위협
   - 내 역할 한 줄
   - 다음 구매 TOP1
   - 현재 구도 / 핵심 경고 1개
4. 사망 화면
   - 부활 시간 + 현재 골드
   - 통계 기본트리 vs 이번 판 최적화
   - TOP1 + 대안 2개
   - 다음 한타 행동 한 줄
5. 상세 화면
   - 상대 위협 TOP5
   - 한타 상세
   - 파워/부활 상세를 접기형으로 보존
   - 평균 레벨/아이템 가치 등은 기본 화면에서 제거하고 상세에만 배치
6. 인게임 미리보기
   - 랜덤 연습 상단에 `🎮 인게임 미리보기`
   - 생존 / 사망 23초 / 부활 5초
   - 일반 대치 / 수적 우세 / 수적 열세 / 상대 캐리 급성장
   - 탱커 / 원딜 / 메이지 / 서포터 / 브루저
   - 실제 LIVE HUD와 같은 렌더러를 사용
   - `PREVIEW · 실제 게임 데이터 아님` 명시
7. 아이템 비교
   - 현재 내장 챔피언 DB의 `기본 트리`와 `통계 기준`을 통계 기준선으로 표시
   - 현재 판 LIVE 엔진의 TOP1을 `이번 판 최적화`로 표시
   - 내장 DB에 LOL.PS/MetaSRC 교차검증 출처가 있는 경우 그대로 출처 표시
   - 이번 버전에서 LOL.PS를 인게임 중 실시간 크롤링하지 않음

안전성
- 추천/조합/위협/아이템 점수 계산식 변경 없음.
- 기존 randomLiveContext / Threat / NextItems / Power / FightPlan 엔진을 재사용하는 UI 레이어.
- 정확한 설치본 DOM `#random` / `#randomIngameShell` 기준으로만 동작.

ARAM Fearless Draft v0.15.23
Date: 2026-09-09

1) PLAYER PROFILE · ROLE MASTERY 전체 프로필 드릴다운
- v0.15.22의 역할 카드 클릭 시 챔피언별 상세만 열리던 흐름을 확장.
- 원딜 / 메이지 / 탱커 / 브루저 / 서포터 / 암살자 역할 카드를 누르면 해당 역할 전적만 기준으로 전체 PLAYER PROFILE을 다시 계산.
- 역할 선택 시 함께 바뀌는 영역:
  · PLAYER INDEX / 등급
  · 최근 폼 / 안정성 / 최고 5경기 폼 / 최고 단일 경기
  · PLAY STYLE RADAR
  · 전투 영향력 / 생존 관리 / 자원 효율 / 교전 참여 / 역할 수행 / 안정성
  · SCOUT REPORT / 플레이 타입 / 강점 / 개선 여지 / 한줄평
  · DEVELOPMENT
  · NEXT OBJECTIVE
- SCOUT REPORT는 선택한 역할 전적만 사용한다는 문구와 역할 내부 강점/약점을 명시.
- NEXT OBJECTIVE도 역할별 핵심 지표(예: 탱커 피해흡수/전열/이니시/CC/생존, 원딜 딜/지속딜/생존/자원효율/교전참여) 중 현재 가장 낮은 축으로 재계산.
- ROLE MASTERY 카드 자체는 전체 전적 기준 점수와 경기 수를 유지하여 다른 역할로 즉시 이동 가능.
- 선택한 역할의 챔피언별 상세는 v0.15.22 드릴다운과 함께 유지.
- 같은 역할을 다시 누르거나 상단 역할 필터 ×를 누르면 전체 종합 프로필로 복귀.
- 역할 표본 수를 '원딜 분석 4/20경기'처럼 전체 전적 대비 표본과 함께 표시하고 소표본 신뢰도를 별도 안내.

2) 상단 업데이트 배지 · 앱 내부 업데이트 확인/적용
- 상단의 '업데이트 완료 / 업데이트 상태' 배지를 클릭 가능한 업데이트 확인 버튼으로 전환.
- 클릭 시 GitHub stable update channel의 update/manifest.json을 즉시 확인.
- 최신 버전인 경우 앱을 종료하지 않고 '최신 버전입니다 · vX.X.X' 메시지 표시.
- 새 버전이 있는 경우 manifest에 지정된 파일을 임시 staging 영역에 먼저 다운로드한 뒤 앱 폴더에 적용.
- 적용 성공 후 사용자가 직접 앱을 끄고 Launcher를 다시 실행할 필요 없이 Electron 앱이 자동 재시작.
- 파일 경로 traversal 차단, HTTPS/GitHub host 제한, 선택적 SHA-256 검증, 업데이트 실패 시 기존 파일 rollback 처리.
- manifest의 min_launcher가 현재 Launcher보다 높으면 앱을 종료하지 않고 새 Launcher 필요 메시지를 표시.
- v0.15.23을 처음 받는 1회는 기존 Launcher v2.0.2 재실행이 필요하며, v0.15.23 이후 일반 파일 패치는 상단 배지에서 직접 확인/적용 가능.

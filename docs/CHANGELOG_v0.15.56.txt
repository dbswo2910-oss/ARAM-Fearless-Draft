ARAM Fearless Draft v0.15.56
Random In-game Item Icons

목표
- 게임 중 아이템 이름을 읽기 전에 그림으로 먼저 인식할 수 있도록 공식 롤 아이템 아이콘을 보강.
- 텍스트를 없애지 않고 `아이콘 + 이름/가격` 구조를 유지해 직관성과 오인 방지를 함께 확보.

변경
1. 사망 상점 `지금 살 것`
   - 추천 하위 부품마다 Data Dragon 공식 아이콘 표시
   - 가격 텍스트는 그대로 유지
   - 최종 코어 목표에도 작은 아이콘 표시
2. LIVE `다음 구매`
   - 추천 코어 이름 앞에 작은 공식 아이콘 표시
   - 살아 있을 때 정보량은 늘리지 않고 기존 카드 안에서만 시각 보강
3. 사망 `이번 판 최적화`
   - 추천 코어 이름에 아이콘 표시
4. `통계 기본트리`
   - 기존 텍스트 트리는 유지
   - 인식 가능한 아이템을 최대 4개까지 아이콘+이름 스트립으로 위에 보강
5. 이미지 소스
   - 현재 item catalog가 반환하는 Data Dragon 버전을 사용
   - `https://ddragon.leagueoflegends.com/cdn/<version>/img/item/<itemId>.png`
   - 이미지 로딩 실패 시 깨진 이미지를 숨기고 텍스트만 남김
6. 코치 표기
   - `INGAME COACH · v0.15.56`

안전성
- 추천 점수, 위협 점수, 아이템 코어 추천 계산, 구매 플래너 수학 로직 변경 없음 (`score_logic_changed:false`).
- 기존 item catalog의 한국어 아이템명 ↔ item ID 매핑을 재사용.
- 실제 게임/미리보기 모두 동일 DOM 렌더 결과를 후처리하므로 별도 가짜 디자인을 만들지 않음.

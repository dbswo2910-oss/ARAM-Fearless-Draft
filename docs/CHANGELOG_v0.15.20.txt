ARAM Fearless Draft v0.15.20
Date: 2026-09-09

LIVE · 상대 장비가치 시야 안정화
- 상대가 시야/Live Client 관측에서 잠시 사라지거나 아이템 슬롯이 비어 보일 때 장비가치가 0 또는 낮은 값으로 급락하던 문제 수정.
- 상대별 마지막으로 정상 관측된 장착 아이템 가치와 아이템 목록을 경기 중 메모리 캐시에 보관.
- 현재 관측 아이템이 통째로 사라지거나 큰 폭으로 부분 누락된 경우 마지막 확인 장비가치를 유지.
- 상대 플레이어 객체 자체가 일시적으로 enemy 목록에서 빠져도 같은 경기에서 마지막 확인 스냅샷을 LIVE 전력 계산에 보존.
- 다시 시야/관측이 복구되어 더 완전한 아이템 정보가 들어오면 즉시 최신 장비가치로 갱신.
- 게임 시간이 되감기거나 우리 팀 로스터가 바뀌면 캐시를 초기화하여 이전 경기 장비가치가 다음 경기에 섞이지 않게 함.
- 소비성 아이템 등 작은 정상 감소는 허용하고, 큰 폭의 슬롯 누락만 시야/관측 공백으로 판단.
- UI 문구를 "현재 관측값 · 미노출 시 마지막 확인값 유지"로 변경.
- 숨겨진 골드/구매 아이템을 추정하지 않음. 마지막으로 실제 관측된 장비만 유지.

기존 v0.15.19 Player Profile, v0.15.18 ROLE 상세보기, Queue 분리, Draft Architecture Guard, FAIR-S는 그대로 유지.

Random Practice · 팀원픽 표시 위치 수정

- 실 Windows 스크린샷 피드백 반영.
- `우리 파티 챔피언` 입력칸 안쪽에 추가했던 `팀원픽` pill은 화면에서 숨김.
- `남은 랜덤 챔피언` 후보에서, 기존 `외부픽`과 같은 슬롯-number 영역에 `팀원픽`을 표시.
- AutoSync로 감지된 파티 현재픽뿐 아니라 사용자가 수동 고정한 파티 챔피언도 오른쪽 후보 풀에서 `팀원픽`으로 표시.
- 같은 후보가 외부 확정픽이면 기존 `외부픽`이 우선하며 `팀원픽`은 중복 표시하지 않음.
- 수동 고정과 AutoSync 표시 전용 상태의 내부 의미는 그대로 유지.
- 추천점수, 조합점수, 밴픽/랜덤 계산 로직은 변경하지 않음 (`score_logic_changed:false`).

검증 범위
- 소스/manifest/runtime wiring/회귀감사로 정적 검증.
- 실제 Windows DPI/폰트/롤 클라이언트 상태의 최종 렌더링은 업데이트 후 사용자 스크린샷으로 확인 필요.

ARAM Fearless Draft v0.15.30 CHANGELOG

핵심: 역할 선택 시 PLAYER PROFILE 전체를 역할 전용 모델로 전환

1. ROLE RADAR
- 전체 PLAYER PROFILE의 PLAY STYLE RADAR는 그대로 유지합니다.
- ROLE MASTERY에서 탱커/원딜/메이지/서포터/브루저/암살자를 선택하면 메인 육각형이 역할 전용 6축으로 변경됩니다.

역할별 6축
- 탱커: 피해 흡수 / 전열 유지 / 이니시 / CC 영향력 / 보호·필 / 생존·지속전
- 원딜: 딜 생산 / 지속딜 / 자원 환산 / 생존 / 교전 참여 / 캐리 수행
- 메이지: 딜 생산 / 포킹 / 공간·제어 / CC 영향력 / 생존 / 자원 효율
- 서포터: 보호·필 / 아군 유지력 / 유틸리티 / CC 영향력 / 교전 참여 / 생존
- 브루저: 딜 생산 / 진입 / 전열 / 지속전 / 생존 / 교전 참여
- 암살자: 순간폭딜 / 후방 접근 / 캐치 / 킬 전환 / 생존 / 리셋·마무리

2. 역할 전용 프로필 내용
역할 선택 시 다음 영역이 동일 역할 표본을 사용하도록 맞춥니다.
- 기존 v0.15.23의 역할별 PLAYER INDEX
- ROLE RADAR
- 6개 세부지표
- PLAY TYPE
- SCOUT REPORT
- 강점/개선 여지
- DEVELOPMENT
- NEXT OBJECTIVE

3. 비교 표본 대기 제거
- 역할 세부지표에서 이전 구간 표본이 부족하다고 '비교 표본 대기'만 표시하지 않습니다.
- 비교가 가능한 경우 최근 5경기 vs 이전 구간 변화량을 표시합니다.
- 비교 표본이 부족하면 '탱커 4경기 기준'처럼 현재 역할 표본 수를 명시합니다.
- 외부 전체 유저 percentile이 없는 상태에서 가짜 백분위를 만들지 않습니다.

4. 역할별 Scout/Type
- 전체 플레이스타일 유형을 역할 프로필에 그대로 재사용하지 않고 역할 수행지표로 역할형 유형을 계산합니다.
- 예: 선이니시형, 전열 버팀목, 지속딜 캐리형, 공간 지배형, 보호 중심형, 지속전 특화형, 처형형 등.
- Scout Report는 해당 역할의 상위/하위 지표, 최근 흐름, 표본 신뢰도를 사용합니다.

5. 역할 전용 성장 목표
- NEXT OBJECTIVE는 역할의 현재 최저 핵심지표를 우선합니다.
- 약 +5점 개선을 목표로 하되 현재 가장 강한 지표가 급락하지 않는 trade-off guard를 함께 표시합니다.
- 단일 지표 상승만으로 실력 향상을 확정하지 않습니다.

주의
- 전체 프로필에서는 기존 PLAY STYLE RADAR가 유지됩니다.
- 역할 선택 시에만 ROLE RADAR로 전환됩니다.
- Scout 문장은 집계 전적에 기반하며 실제 리플레이 장면을 봤다고 표현하지 않습니다.

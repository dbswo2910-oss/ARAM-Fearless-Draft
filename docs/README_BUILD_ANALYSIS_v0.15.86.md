# IN GAME Build Analysis v0.15.86

The Build tab compares two different answers on purpose:

1. Statistical baseline build — the common high-pick/high-win core path stored in the champion database.
2. Current-match optimized build — the v0.15.81 recommendation engine output after current inventory, role and enemy threat context are applied.

The statistical side is a reference, not a live instruction. The current-match side is the actionable recommendation.

The screen also exposes current inventory, top three next purchases, current target recipe, situational pivots, divergence reasons, and a concise conclusion. Existing death-shop calculations remain active and are mounted inside the purchase-priority area.

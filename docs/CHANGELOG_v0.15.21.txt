ARAM Fearless Draft v0.15.21
Date: 2026-09-09

1) 데이터 · 챔피언 상세 Sticky Follow
- 데이터 화면의 "챔피언 상세" 패널을 데스크톱 폭(1050px 이상)에서 sticky 패널로 전환.
- 챔피언 목록 아래쪽까지 스크롤해도 상세 패널이 화면 상단 10px 기준으로 따라오도록 처리.
- 상세 내용이 화면보다 길면 상세 패널 내부만 스크롤 가능하게 max-height/overflow 적용.
- 데이터 DOM이 다시 그려져도 MutationObserver와 챔피언 클릭 후 재탐색으로 sticky 클래스를 다시 적용.
- 모바일/좁은 화면에서는 기존 static 레이아웃 유지.

2) PLAYER PROFILE · 유형 다양화
원인 확인
- v0.15.19의 6개 레이더 축은 ROLE GRADE/핵심축/KP처럼 이미 정규화된 성과값을 여러 축이 공유해 서로 상관이 높았음.
- 그 결과 대부분 축이 비슷한 값으로 모여 육각형에 가까워지고, 절대 임계치형 태그 조건을 통과하지 못하면 '밸런스형' fallback으로 수렴하는 구조였음.

수정
- 기존 PLAYER INDEX와 6개 절대 능력치는 유지.
- 메인 레이더를 별도 PLAY STYLE RADAR로 변경: 교전 적극성 / 생존 지향 / 캐리 지향 / 전열 성향 / 제어·지원 / 안정성.
- 레이더는 단순 절대점수 복제가 아니라, 최근 20경기의 서로 다른 관측축을 만든 뒤 선수 개인 평균 대비 상대강점을 contrast normalization으로 표시.
- 따라서 잘하는 사람은 무조건 큰 육각형, 못하는 사람은 작은 육각형이 되는 구조를 제거하고 '어떤 방식으로 플레이하는가'의 모양이 드러나도록 변경.
- 역할 다양성(entropy), 주 역할 비중, 역할 숙련도까지 유형 판정에 추가.
- '밸런스형' 기본 fallback 제거.
- 15개 유형 후보를 조합식으로 판정: 선봉 돌격형 / 교전 지휘형 / 전열 버팀목 / 안정 캐리형 / 하이리스크 캐리형 / 포킹 압박형 / 팀 조율형 / 자원 환산형 / 저자원 효율형 / 안정 루틴형 / 고점·저점형 / 멀티롤 올라운더 / 역할 스페셜리스트 / 한타 개근형 / 딜 생산형.
- 1개 유형만 고정하지 않고 서로 다른 계열에서 최대 4개 태그를 보여주며 1순위 유형은 별표 강조.
- SCOUT REPORT는 1순위 유형 + 개인 내 가장 강한 성향 + 상대적으로 낮은 성향 + 최근 폼 변화로 조합해 작성.
- FM식 한줄평은 유형별 3종 이상 문구 풀에서 플레이어 식별자 기반으로 안정적으로 선택하여 플레이어마다/유형마다 같은 문구만 반복되는 현상을 완화.
- PLAYER INDEX, ROLE MASTERY, DEVELOPMENT, NEXT OBJECTIVE, Q450/Q2400 분리, v0.15.20 상대 장비가치 시야 안정화는 그대로 유지.

ARAM Fearless Draft v0.15.53
Random In-game Coach · Death Shop Planner

목표
- 사망 중 빌드 화면을 “무슨 코어를 갈지”에서 “지금 가진 골드로 무엇을 살지”까지 연결.
- 기존 HUD 레이아웃은 유지하고 상점 의사결정만 강화.

변경
1. 사망 빌드 화면에 `💰 지금 구매` 플래너 추가
   - 현재 보유 골드
   - 이번 죽음에 바로 살 수 있는 조합 부품
   - 각 부품의 현재 필요한 골드
   - 구매 후 잔여 골드
   - 최종 코어 목표
   - 구매 후 코어 완성까지 남은 골드
2. 보유 부품 반영
   - Live Context에서 현재 아이템 ID/이름을 확인할 수 있을 때 레시피 트리에서 이미 보유한 부품을 소모 처리
   - 보유 부품을 확인하지 못한 실제 LIVE 상태에서는 중복 구매 위험 때문에 정확한 구매 지시를 숨김
3. 조합 계산
   - Data Dragon의 `from` / `into` / `gold.base` / `gold.total`을 사용
   - 완성 코어까지의 남은 비용을 재귀적으로 계산
   - 현재 골드로 완성 가능한 가장 높은 레시피 노드를 찾고, 여러 독립 부품을 함께 살 수 있으면 골드 활용도가 높은 조합을 선택
4. 아이템 카탈로그 확장
   - 한국어 `ko_KR` Data Dragon 아이템 데이터 우선
   - ARAM map 12, 구매 가능 여부, 조합 관계, 기본/총 가격 보존
5. 미리보기
   - 사망 23초 미리보기에서도 같은 플래너 UI를 확인 가능
   - 미리보기는 보유 부품 없음 가정이라고 명시
6. 상단 코치 표기는 v0.15.53으로 노출

안전성
- 챔피언 추천, 위협도, 아이템 코어 추천 점수, 조합 점수 계산식 변경 없음 (`score_logic_changed:false`).
- 기존 v0.15.50~v0.15.52 HUD 위에 상점 행동 레이어만 추가.
- 실제 보유 아이템 상태가 불확실할 때는 잘못된 중복 구매 지시보다 “확인 중”을 우선.

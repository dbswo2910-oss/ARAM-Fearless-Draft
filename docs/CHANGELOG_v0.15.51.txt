ARAM Fearless Draft v0.15.51
Random In-game Coach HUD · Screenshot Polish Phase 2

목표
- v0.15.50 실제 Windows 미리보기 캡처를 기준으로 시각 우선순위를 다시 정리.
- 인게임 화면에서 픽 단계 정보와 중복 정보를 제거해 한눈에 판단 가능하게 함.

변경
1. 인게임 모드 진입 시 픽 단계 UI 숨김
   - 현재 팀/후보 풀 단계 제목
   - 완성 조합 TOP5
   - 픽 분석 쉘
   - 인게임에서 필요 없는 상단 요소가 화면을 차지하지 않도록 정리
2. 미리보기 조작부 압축
   - 생존/사망/부활 버튼 + 상황/역할 선택을 데스크톱 한 줄 툴바로 배치
   - 기존 두 줄 전체폭 셀렉트로 인한 높이 낭비 감소
3. LIVE 핵심 카드 4개 -> 3개
   - 최고 위협
   - 내 역할
   - 다음 구매
   - `현재 구도` 카드는 NOW CALL과 중복이라 기본 화면에서 제거
4. LIVE 카드 가독성 개선
   - 내 역할 카드에 가장 넓은 폭 배정
   - 다음 구매는 녹색 계열로 행동 항목임을 구분
   - 말줄임보다 한두 줄 읽기를 우선
5. 사망 분석 화면 우선순위 변경
   - `이번 판 최적화`를 왼쪽/주요 카드로 승격
   - 통계 기본트리는 보조 정보로 축소
   - 다음 한타 행동 한 줄을 더 읽기 쉽게 강조

안전성
- 추천 점수/위협 점수/아이템 점수/조합 계산식 변경 없음.
- v0.15.50 코치 엔진 위에 적용되는 UI 전용 후처리 레이어.
- 실제 v0.15.50 사용자 캡처에서 확인된 구조를 기준으로 수정.

Scope

- '비교 표본 대기' UX 개선

  탱커 6 / 원딜 6 / 메이지 6 / 서포터 6 / 브루저 6 / 암살자 6

- 기존 전체 PLAY STYLE RADAR 계산을 덮어쓰지 않고 selectedRole일 때만 후처리하도록 설계 PASS

Data consistency checks
- 역할 프로필은 v0.15.23 roleMatches(role)의 동일 역할 경기만 사용합니다.
- 각 경기의 지표는 현재 aramHistoryBaseSignals + aramHistoryRoleBreakdown을 다시 읽습니다.
- 따라서 v0.15.25 CC 영향력과 v0.15.29 Mission/Death Fairness 이후의 현재 ROLE score를 참조합니다.
- PLAYER INDEX 자체는 v0.15.23의 역할 필터 계산을 유지하고, v0.15.30은 ROLE RADAR/세부지표/리포트/성장영역을 그 역할과 일치시킵니다.

Sample behavior
- 현재 역할 최대 최근 20경기로 역할 지표 평균을 계산합니다.
- ROLE RADAR의 현재 값은 최근 최대 5경기를 표시합니다.
- 이전 비교는 최근5 이후 최소 3경기가 있을 때만 표시합니다.
- 이전 표본이 부족하면 사용자 UI에는 '<역할> N경기 기준'을 표시합니다.
- 전세계/전체 플레이어 percentile은 생성하지 않습니다.

Role-specific axes
- 탱커: 피해 흡수 / 전열 유지 / 이니시 / CC 영향력 / 보호·필 / 생존·지속전
- 원딜: 딜 생산 / 지속딜 / 자원 환산 / 생존 / 교전 참여 / 캐리 수행
- 메이지: 딜 생산 / 포킹 / 공간·제어 / CC 영향력 / 생존 / 자원 효율
- 서포터: 보호·필 / 아군 유지력 / 유틸리티 / CC 영향력 / 교전 참여 / 생존
- 브루저: 딜 생산 / 진입 / 전열 / 지속전 / 생존 / 교전 참여
- 암살자: 순간폭딜 / 후방 접근 / 캐치 / 킬 전환 / 생존 / 리셋·마무리

Regression safeguards
- 전체 Player Profile을 열었을 때는 기존 v0.15.21 PLAY STYLE RADAR 유지.
- 역할 선택 상태에서만 v0.15.30 DOM 후처리 적용.
- ROLE MASTERY 카드와 v0.15.22 챔피언별 상세 구조는 삭제/교체하지 않음.
- 역할 선택을 해제하면 v0.15.23이 전체 프로필을 재렌더링하므로 역할 전용 DOM이 잔존하지 않도록 설계.
- SCOUT REPORT는 지표 평균/추세/표본만 사용하며 리플레이 장면 추정 없음.

Known risks / not executed
- 실제 Windows Electron modal에서 역할 카드를 연속 클릭하는 E2E 미실행.
- 실제 사용자 DPI/창 크기에서 6개 radar label 충돌 여부 육안검사 미실행.
- 역할 표본 1~2경기의 문구/레이아웃 실제 화면 확인 필요.
- MutationObserver 기반 후처리가 실제 설치본 DOM 변경 순서에서 항상 마지막에 적용되는지 사용자 환경 확인 필요.

Result
- 자동/정적 검증 PASS.
- 실제 Windows + Riot Client UI E2E는 미검증.

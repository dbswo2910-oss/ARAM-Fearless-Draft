v0.15.66 · 실행 먹통/응답성 핫픽스

문제
- v0.15.60, v0.15.63, v0.15.64, v0.15.65 아이템 이미지 보정 레이어가 모두 main.js에서 순차 실행되고 있었습니다.
- 각 레이어가 MutationObserver와 650~1800ms 주기의 재스캔을 별도로 설치해, 실제 Electron 렌더러에서는 같은 이미지 DOM을 여러 감시기가 반복 확인하는 구조였습니다.
- 정적 회귀검사는 파일 존재/파싱/마커를 확인했지만, 여러 레이어가 한 렌더러에서 동시에 살아 있을 때의 응답성은 검증하지 못했습니다.

수정
- item-art-runtime-v01566.js를 이전 이미지 보정 레이어보다 먼저 실행합니다.
- v0.15.60/0.15.63/0.15.64/0.15.65 이미지 감시 레이어를 readiness marker로 선점하여 초기화 자체를 막습니다.
- 실제 아이템 이미지는 v0.15.66 단일 MutationObserver가 담당합니다.
- 650/700/900/1800ms 전체/반복 스캔 루프를 제거하고, 최초 1회 스캔 + 실제 DOM 변경분만 처리합니다.
- 아이콘 URL의 매 실행 session nonce를 제거해 동일 버전에서는 브라우저 캐시를 재사용합니다.
- v0.15.64/v0.15.65 resolver 이름에는 호환 shim을 제공해 외부 호출 호환성을 유지합니다.
- 추천/밴픽/아이템 점수 계산은 변경하지 않았습니다 (score_logic_changed:false).

검증
- runtime-stability-v01566-audit.js 추가.
- v0.15.66이 먼저 실행된 뒤 역사적 4개 이미지 레이어를 실행하는 VM 시뮬레이션에서 item-art MutationObserver 1개, polling interval 0개를 강제 검증합니다.
- Full Regression Audit에 v0.15.66 응답성 검사를 추가합니다.

실기 확인 포인트
- Windows에서 앱 실행 직후 클릭/스크롤이 즉시 반응하는지
- 랜덤연습/인게임/챔피언DB/Match Lab의 아이템 이미지가 정상 유지되는지
- 아이템 이미지 fallback이 발생해도 반복 깜빡임/CPU 급등이 없는지

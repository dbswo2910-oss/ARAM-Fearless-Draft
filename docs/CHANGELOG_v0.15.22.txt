ARAM Fearless Draft v0.15.22
Date: 2026-09-09

PLAYER PROFILE · ROLE MASTERY 챔피언별 드릴다운

- PLAYER PROFILE의 ROLE MASTERY 카드를 클릭 가능한 역할 상세 버튼으로 변경.
- 탱커 / 메이지 / 원딜 / 서포터 / 브루저 / 암살자 등 역할 카드를 누르면 현재 불러온 전적 중 해당 역할 경기만 챔피언별로 묶어 표시.
- 챔피언별 표시: 경기 수, 승/패, 승률, ROLE GRADE 평균/등급, 최고 ROLE, 표본 경고, 4경기 이상 시 최근 절반 vs 이전 절반 ROLE 흐름.
- 역할마다 서로 다른 핵심 지표를 사용.
  · 탱커: 피해 흡수 / 전열 / 이니시 / CC / 생존
  · 메이지: 딜 생산 / 포킹 / 제어 / CC / 생존
  · 원딜: 딜 생산 / 지속딜 / 생존 / 자원 효율 / 교전 참여
  · 서포터: 보호 / 아군 유지력 / 유틸 / CC / 생존
  · 브루저: 딜 생산 / 진입 / 전열 / 지속전 / 생존
  · 암살자: 순간폭딜 / 후방 접근 / 캐치 / 딜 생산 / 생존
- 동일 역할 카드를 다시 누르면 상세가 닫힘. 다른 역할을 누르면 즉시 해당 역할 챔피언 데이터로 전환.
- Enter / Space 키보드 조작 및 aria-expanded 적용.
- PLAYER PROFILE이 재렌더되어도 MutationObserver로 역할 클릭 기능을 재연결.
- 데이터는 현재 조회해 둔 10인 상세 전적만 사용하며 소표본은 별도 표시.

전적 조회 제한 확인
- v0.15.17 Match Lab 화면 로더는 현재 최대 30경기로 clamp 되어 있음.
- LCU 백엔드 getAramMatchHistory는 현재 최대 40경기를 받을 수 있도록 되어 있음.
- 이번 v0.15.22에서는 사용자의 명시적 요청 전까지 조회 상한은 변경하지 않고 ROLE MASTERY 드릴다운만 추가.

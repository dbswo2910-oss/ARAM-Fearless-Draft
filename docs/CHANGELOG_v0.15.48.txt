ARAM Fearless Draft v0.15.48

랜덤 연습 Focus UI 정리

1. 랜덤 연습 화면을 정보 과부하가 덜한 구조로 정리
- 현재 선택/팀 입력과 후보 챔피언 영역을 같은 상단 2열 구조로 묶을 수 있도록 함
- 좁은 화면에서는 자동 1열 전환

2. 후보 챔피언 풀 접기/펼치기
- 기본 화면에서 후보 풀을 컴팩트하게 접어 세로 길이를 줄임
- 필요할 때 바로 펼쳐 기존 입력 기능 사용 가능

3. 추천 결과 TOP 5 집중
- 추천 후보가 많을 경우 기본적으로 상위 5개만 표시
- 나머지는 '추천 더 보기'로 확인
- 장문의 추천 이유는 기본 2줄로 제한

4. '이번 선택의 핵심' 추가
- 현재 1순위 추천의 핵심 이유를 추천 목록 위에 한 줄로 요약
- 새로운 추천 점수를 만들지 않고 기존 화면 결과를 요약해서 표시

5. 하단 정보 탭화
- 빠른 판단
- 완성 조합
- 조합 분석
- 상세
- 기존 정보를 밑으로 계속 쌓지 않고 선택한 정보만 표시

6. 비파괴/적응형 적용
- 랜덤 연습 화면을 여러 selector/제목 패턴으로 탐지
- 드래프트 작업대는 fallback 대상에서 명시적으로 제외
- 원본 이벤트 리스너를 유지하기 위해 가능한 경우 기존 DOM을 이동/숨김 방식으로 재사용
- 추천 점수 및 조합 계산식은 변경하지 않음

주의
- 저장소에는 설치본 index.html baseline이 포함되어 있지 않아 실제 Windows 랜덤 연습 화면의 DOM 조합은 자동 검사만으로 완전 검증할 수 없음
- 실제 Riot Client 픽창/벤치/리롤 연동, DPI/폰트 환경은 사용자 화면 검수가 필요함

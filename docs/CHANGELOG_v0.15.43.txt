v0.15.43 · 듀오 과집중 밸런스 + 드래프트 UI 재배치 + 위험 알람

1. 칼바람 듀오 과집중 감쇠
- 특정 챔피언 이름을 하드코딩하지 않고 parts.contrib.synergy 전체에 동일 규칙 적용.
- 중간 수준의 듀오 시너지는 유지하고, +12 초과부터 점진적 체감수익을 적용.
- 최종 유효 듀오 기여 상한은 22점.
- 듀오와 41루트가 동시에 매우 큰 경우에만 최대 2.5점의 중복 보상 감쇠 추가.
- 픽뿐 아니라 현재 세트 밴 위협 점수에도 동일 원칙 적용.
- 점수 상세에 원 듀오값 → 유효 듀오값과 감쇠량을 표시.
- 런타임 전체 챔피언 풀 진단 함수 aramDuoBalanceAuditV01543 제공. 예시 챔피언이 아닌 실제 현재 조합 기준 상위 과집중 후보를 최대 30명까지 확인 가능.

2. 드래프트 빌더 UI 재배치
- 1행: 1차밴 1~3밴 // 실시간 다음 픽 추천 TOP 6
- 2행: 2차밴 4~5밴 // 우리 4~5밴 추천 TOP 6
- 3행: 현재 픽 입력
- 4행: 픽 판단
- 5행: 챔피언 풀 · 현재 세트 / 하드피어리스 상태
- 작은 화면에서는 자동 1열 스택.
- 기존 DOM ID와 계산 함수는 유지하고 렌더 이후 위치만 재배치.

3. DRAFT EMERGENCY ALERT
- 픽 판단 상단에 현재 공개된 상대 조합의 가장 위험한 1~2개 축만 노출.
- CC/CATCH, 다이브, 포킹, 광역 한타 연계를 현재 N픽 밀도 기준으로 판정.
- 비상/경고 등급, 주요 원인 챔피언, 우선 대응 방향을 짧게 표시.
- 추천 점수를 큰 폭으로 강제 변경하지 않고 현재 v0.15.42의 제한적 컨텍스트 보정과 병행.

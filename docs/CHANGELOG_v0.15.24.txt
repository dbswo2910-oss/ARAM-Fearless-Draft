v0.15.24 · 시간대 전력 재설계

1. LIVE의 기존 실시간 전력 지표를 '시간대 전력'으로 재정의했습니다.
2. 시간대 전력 계산에서 현재 생존 인원, 부활 상태, 최근 60초 킬/킬 흐름을 완전히 제외했습니다.
3. 현재 정상 5:5로 리셋된 상황을 가정하고 다음 5개 구조적 요소만 사용합니다.
   - 장비 실전가치
   - 완성 코어 아이템 수
   - 평균 레벨
   - Lv.6 / Lv.11 / Lv.16 핵심 레벨 도달 타이밍
   - 현재 시간대 조합 성장곡선
4. 코어 아이템은 Live Client 아이템 가격/이름을 이용해 완성템 성격의 아이템만 보수적으로 집계합니다. 장화, 수호자 계열, 물약/영약/와드류는 제외합니다.
5. 상대 아이템 미노출 시 v0.15.20의 마지막 확인 장비가치 메모리를 그대로 사용합니다.
6. 작은 변화가 화면에서 계속 흔들리지 않도록 시간대 전력 점수에 dead-band + 완충(smoothing)을 적용했습니다.
7. UI 문구를 '실시간 전력 우위'에서 '시간대 전력 · 정상 5:5 기준'으로 변경하고 각 산출 요소를 직접 표시합니다.
8. 우세/열세의 가장 큰 원인 1~2개를 자동으로 설명합니다.
9. 다음 시간 구간의 성장곡선도 함께 표시하되 현재 점수에는 현재 구간을 중심으로 반영합니다.

주의:
- 승률 예측값이 아닙니다.
- 순간적인 한타 인원차나 최근 킬 흐름을 의도적으로 반영하지 않습니다.
- 실제 Windows + Riot Client에서의 장시간 E2E 시각 검수는 별도로 필요합니다.
